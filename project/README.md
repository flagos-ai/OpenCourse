# Project Resources

This directory contains program-level resources that support adoption of FlagOS OpenCourse but are not course delivery assets.

- `overview/`: program background and course-design rationale.
- `curriculum-adoption/`: syllabus examples and adoption references.
- `faculty-development/`: faculty development resources.
- `student-learning-outcomes/`: student activities and outcomes.
- `university-collaboration/`: collaboration models and resource applications.
