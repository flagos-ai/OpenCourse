# About FlagOS OpenCourse

This directory introduces FlagOS OpenCourse for international institutions and
faculty. The [project overview](../overview.en.md) explains its educational
context; the [course structure](../course-structure.en.md) defines the 48-hour
core curriculum and its optional pre-course. Teaching resources and lab scripts
are maintained at the repository root in [lectures/](../../lectures/) and
[labs/](../../labs/).

| Topic | Document |
| --- | --- |
| Institutional adoption and partnership | [Institutional adoption](institutional-adoption.md) |
| Faculty support | [Faculty support](faculty-support.md) |
| Syllabus template | [Syllabus template](syllabus-template.md) |
| International case study | [China–Africa first cohort](china-africa-first-cohort.md) |

Completed faculty-development deliveries are independent archives under
[editions/](../../editions/), rather than living program documentation.
