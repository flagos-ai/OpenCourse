# Labs

This directory is the maintained source for FlagOS hands-on labs. Select and copy only the labs used when preparing a completed training edition.

## Get the lab scripts

Clone the current OpenCourse repository from GitLink, then open the directory for the lab you need:

```bash
git clone https://gitlink.org.cn/flagos-ai/OpenCourse.git
cd OpenCourse
```

## Structure

- `pre-course/`: introductory course labs.
- `modules/`: labs aligned to the five-module sequence.
- `special-topic-labs/`: standalone topics outside the module sequence.
- `online-lab-guide/`: platform and environment guidance.
- `online-lab-assistant/`: the optional assistant installation package.

## Maintenance

Edit labs here. Each lab README contains its learner instructions and platform requirements. Completed training editions are independent snapshots and are not automatically synchronized.
