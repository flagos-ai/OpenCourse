# FlagOS OpenCourse

Open teaching resources for the FlagOS AI system software stack: lecture resources, hands-on labs, and university-adoption materials.

[中文](README.zh-CN.md) | English

## Repository layout

| Directory | Purpose |
| --- | --- |
| [`lectures/`](lectures/) | Maintained lecture resources for the introductory course and five modules. |
| [`labs/`](labs/) | Maintained hands-on labs, platform guidance, and the Online Lab Assistant. |
| [`about-opencourse/`](about-opencourse/) | OpenCourse background, course structure, adoption, faculty-support, and curriculum-template resources. |
| [`editions/`](editions/) | Self-contained archives of completed training deliveries. |
| [`best-practices/`](best-practices/) | Standalone technical tutorials for FlagOS components. |

## Maintenance model

Maintain current teaching materials in `lectures/` and `labs/`. Completed training deliveries are preserved as independent editions under `editions/`, together with their associated program materials, talks, and partnership documents. Editions are not automatically updated when mainline materials change.

GitHub is the canonical repository. GitLink and GitCode mirror the same repository paths for users who cannot access GitHub.
