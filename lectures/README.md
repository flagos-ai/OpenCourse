# Lecture Resources

This directory contains the maintained FlagOS OpenCourse lecture resources.

Downloadable lecture packages are published in the
[mainline course release](https://github.com/flagos-ai/OpenCourse/releases/tag/mainline-course-v1.0.0):

- [Chinese lectures](https://github.com/flagos-ai/OpenCourse/releases/download/mainline-course-v1.0.0/opencourse-mainline-v1.0.0-lectures-zh.zip)
- [English lectures](https://github.com/flagos-ai/OpenCourse/releases/download/mainline-course-v1.0.0/opencourse-mainline-v1.0.0-lectures-en.zip)

The repository keeps navigation and lightweight course documentation; the
large lecture binaries are distributed as release assets.

- [`zh/`](zh/): Chinese course materials, including the introductory course, five modules, and the 48-lecture collection.
- [`en/`](en/): English lecture-slide collection organized by module.

Course materials are arranged as an introductory course followed by five modules:

1. AI systems software foundations and heterogeneous computing
2. High-performance AI operators and operator engineering
3. AI compiler principles and optimization
4. Distributed parallel training and communication
5. Performance analysis and next-generation kernel generation

Use the README in the selected language directory to navigate the corresponding materials.
