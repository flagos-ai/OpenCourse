# FlagOS OpenCourse

面向 FlagOS AI 系统软件栈的开放教学资源，包含课程课件、动手实验和高校课程采用资料。

中文 | [English](README.md)

## 仓库结构

| 目录 | 用途 |
| --- | --- |
| [`lectures/`](lectures/) | 通识课与五个核心模块的主线课件。 |
| [`labs/`](labs/) | 主线实验、环境指南和 Online Lab Assistant。 |
| [`about-opencourse/`](about-opencourse/) | OpenCourse 项目背景、课程结构、课程采用、师资支持与课程大纲资料。 |
| [`editions/`](editions/) | 已完成培训的独立归档。 |
| [`best-practices/`](best-practices/) | FlagOS 组件的独立技术教程。 |

## 维护方式

当前教学材料维护在 `lectures/` 和 `labs/` 中。完成的培训交付以独立版本归档在 `editions/` 下，并包含相关项目资料、技术分享和合作材料。归档版本不会随主线材料自动更新。

GitHub 是主仓库；GitLink 和 GitCode 为同一路径的镜像，方便无法访问 GitHub 的用户使用。
