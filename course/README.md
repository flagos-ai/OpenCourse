# FlagOS OpenCourse

This directory contains the maintained teaching assets for the FlagOS OpenCourse.

## Contents

- [Lecture resources](lecture-resources/): pre-course and five-module teaching materials in Chinese and English.
- [Lab materials](lab-materials/): runnable labs, online-lab guidance, platform variants, and the lab registry.

Project background, faculty-development guidance, student outcomes, and university collaboration materials are maintained in [`../project/`](../project/).

Most Office and PDF assets retain their original instructional language. Navigation, filenames, and Markdown documentation are maintained in English.
