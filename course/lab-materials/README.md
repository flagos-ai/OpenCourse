# Lab Materials

This directory is the single maintenance location for FlagOS course labs.

## Lab structure

- `pre-course/`: labs paired with the introductory course.
- `modules/`: module-aligned labs; each platform variant is stored beneath its module.
- `special-topic-labs/`: standalone lab topics that are not part of the five module sequence.
- `online-lab-guide/`: environment and platform-use guidance.
- `online-lab-assistant/`: the optional Online Lab Assistant installation package.

Use [lab-registry.yaml](lab-registry.yaml) to locate a lab by stable ID, module, and platform.

## Platforms

The first maintained platform variant is `iluvatar-corex-bi-v150`. The edge-device lab is maintained separately for `k3-board`. Future variants are added alongside existing platform directories without changing lab IDs.

## Maintenance

Edit labs here. Program editions are frozen snapshots selected from this directory and do not automatically receive later mainline changes.
