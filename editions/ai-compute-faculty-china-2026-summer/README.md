# AI Compute Faculty Development — China 2026 Summer

This directory is the lightweight repository index for the China 2026 Summer
faculty-development archive. The complete delivered materials are distributed
as the [China 2026 Summer archive release](https://github.com/flagos-ai/OpenCourse/releases/tag/edition-ai-compute-faculty-china-2026-summer).

The release contains the lecture decks, lab teaching materials, talks,
demonstrations, program overview materials, and partnership materials delivered
for this training. Large binary files are distributed through the release and
are not duplicated in the Git working tree.
